# 소설 인명 용어집

중국 웹소설의 회차 URL 또는 붙여넣은 원문에서 **사람 이름만 추출**하고, 문맥에 맞는 한국어 표기로 바꿔 작품별 용어집에 누적하는 Cloudflare Pages 앱입니다.

## 주요 기능

- 회차 URL에서 본문 자동 불러오기
- 중국식·일본식·서양식·판타지 인명을 문맥에 맞게 한국어로 표기
- 작품별 용어집을 브라우저 `localStorage`에 저장
- 같은 작품의 다음 회차를 처리할 때 기존 표기를 유지하고 새 인명만 추가
- 인명 직접 수정·추가·삭제
- `원문 = 한국어` 형식으로 복사 및 TXT 저장
- 전체 작품 JSON 백업·복원
- 처리한 회차 URL 기록

## 파일 구조

```text
index.html

_headers

  api/
    extract.js
    fetch-url.js
```

## 배포

현재 Cloudflare Pages 프로젝트의 GitHub 저장소 루트에 파일을 그대로 올리고 commit하면 다시 배포됩니다. 별도 프레임워크나 빌드 명령은 필요하지 않습니다.

## Gemini API Key

사이트의 `Gemini 설정`에서 API Key를 입력하거나, Cloudflare Pages 프로젝트 설정에 다음 Secret을 추가할 수 있습니다.

```text
GEMINI_API_KEY
```

Secret을 등록하면 화면의 API Key 칸은 비워도 됩니다. 기본 모델은 다음과 같습니다.

```text
gemini-3.1-flash-lite
```

## 저장 위치

작품과 용어집은 사용 중인 브라우저의 `localStorage`에 저장됩니다.

- 같은 브라우저에서는 다시 접속해도 유지됩니다.
- 다른 기기와 자동 동기화되지는 않습니다.
- 브라우저 데이터를 삭제하면 사라질 수 있으므로 주기적으로 `전체 백업`을 사용하세요.

## URL 불러오기 제한

일반적인 소설 페이지와 GBK/GB2312 인코딩을 처리하지만, 로그인·봇 차단·JavaScript 렌더링이 필요한 사이트에서는 실패할 수 있습니다. 이 경우 회차 본문을 원문 칸에 직접 붙여넣으면 됩니다.

## 출력 예시

```text
夏长啸 = 하장소
丹尼尔 = 대니얼
江户川乱步 = 에도가와 란포
```
